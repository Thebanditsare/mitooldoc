# 安全注意事项

解锁、ROOT、线刷等操作存在风险，开始前请仔细阅读。

## 数据风险

以下操作会**清除手机所有数据**：

- 解锁 Bootloader
- 线刷（清除 userdata）
- 锁定 Bootloader

请在操作前备份以下内容：
- 照片和视频
- 聊天记录
- 验证码工具
- 工作文档

## 设备风险

以下情况可能导致手机无法正常开机：

- 使用不匹配机型的资源文件
- 操作过程中断开 USB 连接
- 电脑在操作过程中休眠

### 如果手机变砖

| 状态 | 恢复方法 |
| --- | --- |
| 能进 Fastboot | 使用官方线刷包恢复 |
| 能进 EDL（9008 模式） | 使用授权工具救砖 |
| 完全黑屏 | 需联系售后维修 |

## 安全建议

| 项目 | 建议 |
| --- | --- |
| USB 连接 | 使用主板直接连接的 USB 接口 |
| 数据线 | 使用品牌数据线，不要用仅充电线 |
| 电量 | 确保手机电量在 50% 以上 |
| 电脑 | 接通电源，关闭休眠 |
| 其他软件 | 关闭手机助手、刷机精灵等 |

## 操作守则

- 不要中断正在执行的操作
- 按页面步骤顺序操作，不要跳过
- 注意查看日志区的提示信息
- 出现异常时不要反复点击按钮

## 出现异常时

1. 保持当前状态，不要拔插设备。
2. 截图保存日志。
3. 查看 [故障排查](/guide/troubleshooting)。
4. 联系作者时提供日志截图和设备型号。
