# 故障排查

本页用于定位常见操作失败问题。

## 遇到问题先保留

- 当前页面状态（不要关闭）
- 日志区的内容
- 设备当前状态（开机/关机/Fastboot/黑屏）

## ADB 问题

| 现象 | 处理 |
| --- | --- |
| 检测不到设备 | 换数据线、检查 USB 调试授权、关闭其他手机助手 |
| 显示 unauthorized | 在手机上点击允许 USB 调试 |
| 推送文件失败 | 检查手机存储空间 |

## Fastboot 问题

| 现象 | 处理 |
| --- | --- |
| 检测不到设备 | 安装 Fastboot 驱动（设备管理器 → 更新驱动） |
| 刷写失败 | 检查镜像文件是否完整，分区名是否正确 |
| 不进 Fastboot | 关机后按住音量减+电源键手动进入 |

## 解锁问题

**解锁中途窗口关闭了？**

重新打开工具箱，进入「小米解锁 BL」，如有进度缓存会提示继续。

**执行到某步卡住了？**

查看日志最后一行，确定卡在哪一步。常见原因：等待设备重启、等待手动确认。按照页面提示操作。

## ROOT 问题

**ROOT 后不开机？**

重启到 Fastboot，刷回原始 boot 镜像。

**提取镜像失败？**

检查网络连接（卡刷包提取需要下载文件），或尝试手动提供镜像。

## 备份问题

**备份很慢？**

应用数据量大时需要较长时间，可以取消勾选不重要的应用。

**恢复后应用闪退？**

恢复的数据可能与当前系统版本不兼容。重新安装应用即可。

## 需要反馈问题时

提供以下信息给作者：

1. 工具箱版本号（个人中心可查看）
2. 设备型号和系统版本
3. 出错时的日志截图
4. 执行到哪一步时出错
