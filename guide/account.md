# 卡密登录与个人中心

## 登录界面

![登录界面](/login-window.png)

打开工具箱后，在登录界面输入卡密并点击「登录」。等待服务器验证（通常 1-3 秒）。

<img class="doc-screenshot is-narrow" src="/screenshots/auth-login.png" alt="HanfyBox 登录界面">

### 登录失败处理

| 提示 | 处理方式 |
| --- | --- |
| 卡密无效 | 检查是否输入正确，注意区分大小写 |
| 次数用完 | 联系作者获取新卡密或充值次数 |
| 网络失败 | 检查网络连接，确认能访问服务器 |
| 版本过低 | 下载最新版工具箱 |

## 个人中心

登录后点击侧边栏「个人中心」，可以查看：

- 当前卡密（可点击眼睛图标显示/隐藏）
- 剩余可用次数
- 登录时间
- 工具箱版本号

点击复制按钮可以将卡密复制到剪贴板。

## 次数说明

每张卡密有使用次数限制。以下操作会消耗次数：

- 成功解锁一台设备
- 成功 ROOT 一台设备

## 登录有效期

工具箱关闭后需要重新登录，这是正常现象。
