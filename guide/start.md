# 快速开始

本页介绍第一次使用工具箱的完整准备流程。

## 系统要求

- Windows 10 或 Windows 11 系统
- 可用的 USB 数据接口
- 稳定的网络连接

## 下载与启动

1. 从作者提供的渠道下载工具箱压缩包。
2. 解压到不含中文和空格的目录（如 `D:\FlashToolbox`）。
3. 运行 `FlashToolbox.exe`。

## 登录

启动后首先看到登录界面。输入卡密，点击「登录」。

<img class="doc-screenshot is-narrow" src="/screenshots/auth-login.png" alt="登录界面">

| 提示 | 含义 |
| --- | --- |
| 登录成功 | 卡密有效，进入主界面 |
| 卡密无效 | 输入错误或卡密不存在 |
| 次数用完 | 该卡密的可用次数已耗尽 |
| 网络失败 | 无法连接服务器，检查网络 |
| 版本过低 | 需要更新工具箱 |

登录成功后进入主界面。左侧是功能菜单，右侧是当前功能的操作区，底部显示操作日志。



## 连接手机

工具箱的大多数功能需要手机通过 USB 连接电脑。

### 开启 USB 调试

1. 打开手机「设置」→「我的设备」→「全部参数」。
2. 连续点击「MIUI 版本」7 次，直到提示已进入开发者模式。
3. 返回「设置」→「更多设置」→「开发者选项」。
4. 开启「USB 调试」。

### 连接

1. 用数据线连接手机和电脑。
2. 手机上弹出「允许 USB 调试」时，勾选「一律允许」并确认。
3. 在工具箱对应页面点击检测按钮，确认工具能识别你的设备。

## 配置资源地址

部分功能需要下载设备资源文件。进入「设置」页面，在资源地址一栏填入作者提供的云盘地址，工具会在需要时自动下载。

## 不建议的操作

- 执行过程中关闭工具箱
- 刷写或解锁中途拔掉数据线
- 同时运行其他手机助手类软件
- 使用仅充电线（无法传输数据）
