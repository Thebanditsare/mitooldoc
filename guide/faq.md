# 常见问题

## 卡密相关

**登录时提示次数用完？**

每张卡密有使用次数限制。联系作者获取新卡密或充值。

**卡密可以多人共用吗？**

可以，但多人共用会共同消耗次数。

## 设备检测

**检测不到设备？**

1. 检查数据线是否支持数据传输（仅充电线不行）
2. 检查手机上是否弹出授权窗口，需要点击允许
3. 尝试更换 USB 接口或数据线
4. 关闭其他手机助手类软件

**Debug 模式和正常模式的区别？**

Debug 模式用于测试，不会执行真实操作也不消耗卡密次数。正常使用请关闭 Debug 模式。

## 解锁相关

**解锁和 ROOT 的区别？**

解锁是解除系统引导锁（会清除数据），ROOT 是获取系统最高权限（需要先解锁）。

**解锁中途断了怎么办？**

重新打开工具箱，进入「小米解锁 BL」页面。工具会自动检测之前的进度并提供继续选项。

**解锁后还能收到系统更新吗？**

可以，解锁不影响系统更新。

## ROOT 相关

**ROOT 后无法开机？**

进入 Fastboot 模式，刷回原始镜像即可恢复。

**选哪个 ROOT 管理器？**

不确定的话选默认的「Magisk Alpha」即可，兼容性最好。

## 备份恢复

**备份文件在哪里？**

保存在工具箱目录下的 `Backups` 文件夹中。

**备份数据能跨设备恢复吗？**

不建议。不同设备之间的应用数据可能不兼容。

## 资源下载

**下载资源失败？**

1. 检查「设置」中的资源地址是否填写正确
2. 确认网络能访问该地址
3. 联系作者确认资源服务器状态
