# 备份恢复

本页介绍如何使用工具箱备份和恢复手机上的应用数据。

## 前置条件

备份恢复有两种模式：

- **普通模式**：适用于满足条件的小米/红米高通设备（工具会自动判断）
- **高级模式**：适用于已 ROOT 的设备（需要手动开启）

## 操作流程

### 第一步：检测设备

连接设备后，点击 **「检测设备」**。工具会判断你的设备是否满足备份条件。

### 第二步：生成应用列表

点击 **「生成应用列表」**，工具会读取你手机上安装的所有应用并列出。

每个应用可以单独设置：

- 勾选「备份」：备份该应用的 APK 安装包
- 勾选「数据」：备份该应用的用户数据（聊天记录、存档等）

::: tip
取消勾选「备份」会自动取消勾选「数据」。如果你只想备份 APK 不备份数据，取消「备份」勾选即可。
:::

### 第三步：开始备份

1. 确认需要备份的应用已勾选。
2. 点击 **「开始备份」**。
3. 等待日志显示完成。

备份文件保存在工具箱目录下的 `Backups` 文件夹中。

### 第四步：恢复备份

1. 点击 **「开始恢复」**。
2. 在弹出窗口中选择之前备份的文件夹。
3. 等待恢复完成。

## 注意事项

::: warning 重要
- 恢复操作会覆盖应用当前数据，请确认选择了正确的备份。
- 不建议恢复系统应用的数据。
- 备份大应用（如微信）可能需要较长时间。
:::
