# 捐赠入口

捐赠页面用于展示收款码，方便用户自愿支持工具维护。

## 入口位置

可从以下位置进入捐赠页面：

- 侧边栏「捐赠」菜单项（图标：爱心）
- 解锁成功页面 -「捐赠」按钮
- ROOT 成功页面 -「捐赠」按钮

## 使用方式

1. 打开捐赠页面。
2. 选择支付宝或微信。
3. 使用对应 App 扫码。
4. 按 App 内提示完成付款。

<img class="doc-screenshot" src="/screenshots/donate-page.png" alt="捐赠支持页面">

## 说明

捐赠是自愿行为，不影响工具的任何功能。工具箱不会因为未捐赠而限制功能使用。

捐赠金额由用户自行决定，按自身情况支持即可。
