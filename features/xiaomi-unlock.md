# 小米解锁 BL

本页介绍如何使用工具箱解锁小米手机的 Bootloader。

## 支持哪些机型

工具箱目前支持以下平台：

| 平台 | 对应机型 |
| --- | --- |
| 8S Gen 3 / 7+ Gen 3（SM8635 / SM7675） | Redmi Turbo 3、小米 Civi 4 Pro、小米平板 7 Pro |
| 8 Gen 3（SM8650） | 小米 14 / 14 Pro / 14 Ultra、MIX Flip、MIX Fold 4、Redmi K70 Pro、K80 |
| 8 Elite（SM8750） | 小米 15 / 15 Pro / 15 Ultra、Redmi K80 Pro |
| 8 Gen 2（SM8550） | 小米 13 / 13 Pro / 13 Ultra、Redmi K60 Pro |
| 更新平台 | 第五代骁龙 8 系列 |

工具箱会自动检测你的设备芯片和机型，匹配对应的解锁方案。

::: warning 8S Gen 3 适配要求
8S Gen 3 / 7+ Gen 3 方案仅适用于 HyperOS 2.0 及以上，且安全补丁日期早于 2026-02-01 的设备。
:::

## 操作步骤

解锁分为五个步骤，按页面提示依次完成即可。

### 第一步：连接设备

1. 用数据线将手机连接到电脑。
2. 手机需要开启「USB 调试」（设置 → 更多设置 → 开发者选项 → USB 调试）。
3. 点击页面上的 **「检测设备」** 按钮。
4. 等待工具识别设备信息。

<img class="doc-screenshot" src="/screenshots/unlock-connect-device.png" alt="连接设备页面">

::: tip 提示
如果检测不到设备，检查手机上是否弹出了「允许 USB 调试」的确认框，需要点击允许。
:::

检测成功后，页面会显示你的设备序列号、机型名称和芯片型号。点击 **「下一步」** 继续。

### 第二步：检查方案

进入此步骤后，工具会自动匹配适合你设备的解锁方案。

- 如果匹配成功，会显示方案名称。
- 如果显示"暂不支持"，说明你的设备芯片暂未适配。

<img class="doc-screenshot" src="/screenshots/unlock-check-scheme.png" alt="检查解锁方案页面">

匹配成功后点击 **「下一步」**。

### 第三步：确认解锁

此页面会列出解锁操作的重要提示，请仔细阅读：

- 解锁会**清除手机所有数据**，请提前备份照片、联系人等重要资料。
- 操作过程中**不要断开 USB 连接**。
- 确保电脑不会自动休眠。

<img class="doc-screenshot" src="/screenshots/unlock-confirm.png" alt="确认解锁页面">

阅读并理解风险后，勾选确认框，点击 **「开始解锁」**。

### 第四步：执行解锁

工具会自动执行解锁流程。根据设备和方案不同，过程可能持续 5-15 分钟。

<img class="doc-screenshot" src="/screenshots/unlock-ready.png" alt="执行解锁准备页面">

执行期间：
- 手机会多次重启，这是正常现象。
- 屏幕可能出现花屏或黑屏，不要惊慌。
- 部分步骤需要你手动操作（如按住音量键进入 Fastboot），页面会弹出提示等你确认。

<img class="doc-screenshot" src="/screenshots/unlock-running-step6.png" alt="执行解锁进度页面">

**如果窗口意外关闭**：重新打开工具箱，进入本页面后会提示"发现上次解锁进度"，点击「继续」即可从断开的位置恢复。

### 第五步：完成

解锁成功后进入完成页面，显示解锁统计信息。

<img class="doc-screenshot" src="/screenshots/unlock-success.png" alt="解锁成功页面">

::: warning 后续步骤
解锁后需要使用官方线刷包刷回系统才能正常开机。工具会在最后一步提示这一点。
:::

## 常见问题

**Q：解锁失败怎么办？**

查看页面底部的日志，找到失败的具体步骤。常见原因：
- USB 连接不稳定，换一根数据线试试。
- 资源文件下载不完整，检查网络或重新执行。
- 设备不满足方案要求（如安全补丁版本过高）。

**Q：解锁后还能收到系统更新吗？**

可以。解锁不影响系统更新，但更新后 BL 保持解锁状态。

**Q：解锁后可以重新上锁吗？**

可以，但不建议。重新上锁会再次清除数据，且某些设备上锁后可能无法开机。
