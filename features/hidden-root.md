# 隐藏 ROOT

本页介绍如何在已 ROOT 的设备上隐藏 ROOT 状态，防止银行、游戏等应用检测到 ROOT。

## 前置条件

- 设备已获取 Root 权限
- 设备系统为 Android 12 或以上

## 操作流程

1. 进入「隐藏 ROOT」页面。
2. 确保设备已连接并授权 ADB。
3. 点击 **「开始执行」**。

工具会自动完成以下操作：

1. 下载隐藏组件资源
2. 推送资源到设备
3. 识别你的 ROOT 管理器类型
4. 安装隐藏模块
5. 导入防检测配置
6. 启用隐藏策略

过程中设备会重启两次，这是正常的，无需手动操作。

## 完成后

隐藏 ROOT 完成后，大部分检测 ROOT 的应用将无法检测到你的 ROOT 状态。

## 注意事项

::: warning 注意
- 不同品牌的设备效果可能不同。OPPO/一加设备需要额外处理。
- 如果某些应用仍能检测到 ROOT，可能是应用使用了更新的检测手段。
- 模块更新后可能需要重新执行本流程。
:::
