# 一加线刷

本页介绍如何使用工具箱给一加手机线刷系统。

## 前置条件

- 设备处于 Fastboot 模式（关机后按住音量减+电源键）
- 已准备好线刷包（`.zip` 卡刷包或解包后的镜像目录）

## 操作流程

### 第一步：选择刷机包

点击 **「选择刷机包」**，支持两种方式：

1. **选择目录**：选择包含 `payload.bin` 或 `.img` 镜像文件的目录。
2. **选择卡刷包**：直接选择 `.zip` 格式的卡刷包，工具会自动解压。

### 第二步：配置刷写选项（可选）

| 选项 | 说明 |
| --- | --- |
| 清除数据 | 勾选后刷写完成会清除 userdata，相当于恢复出厂设置 |
| 强制重建分区 | 如果提示分区错误，勾选此项重新构建动态分区 |
| DDR 类型 | 部分机型需要指定 DDR4 或 DDR5，一般保持「自动」即可 |

### 第三步：读取分区表（可选）

点击 **「读取分区表」** 可以查看设备当前的分区信息，包括分区名称和大小。

### 第四步：开始线刷

确认设备已进入 Fastboot 模式后，点击 **「开始线刷」**。

执行过程中：
- 设备会自动进入 fastbootd 模式
- 工具按顺序逐个刷写分区镜像
- 日志区实时显示当前进度

整个过程通常需要 3-8 分钟。

### 第五步：完成

刷写完成后，如果勾选了清除数据，设备会自动重启。否则需要手动重启。

## 注意事项

::: warning 重要
- 刷入错误的刷机包可能导致设备无法开机。请确认包与机型匹配。
- 刷写过程中不要断开 USB 连接。
- 刷写前建议备份重要数据。
:::
